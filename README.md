# Retail Sales Analytics Dashboard

## Project Overview
This project is an end-to-end Retail Sales Analytics solution built using Python, MySQL, and Power BI. The objective of the project was to analyze retail sales performance, customer behavior, profitability trends, and regional business insights using real-world analytical workflows.

The project demonstrates the complete data analytics pipeline including:
- Data Cleaning using Python (Pandas)
- SQL-based Business Analysis in MySQL
- Interactive Dashboard Development in Power BI
- Business Insight Generation using Visual Analytics

## Tools & Technologies Used
- Python (Pandas)
- MySQL
- Power BI
- GitHub

## Project Workflow
1. Data Cleaning & Preprocessing (Python)
Performed data cleaning and preprocessing using Pandas in Google Colab:
- Handled inconsistent date formats
- Converted columns into appropriate data types
- Checked missing values and duplicates
- Prepared cleaned dataset for SQL and Power BI analysis

2. SQL Business Analysis (MySQL)
Performed business-oriented analysis using SQL queries:
- Monthly sales and profit trend analysis
- Region-wise profitability analysis
- Top customer analysis
- Product and sub-category performance analysis
- Loss-making category identification

3. Dashboard Development (Power BI)
Built an interactive dark-themed Power BI dashboard to visualize:
- Monthly Profit Trends
- Regional Profitability
- Customer Segment Analysis
- Category & Sub-Category Performance
- Top Customers by Sales
- Sales Distribution across Categories
The dashboard was designed to provide clear business insights and support decision-making through visual analytics.

## Business Problems Solved
- Identified top-performing product categories
- Analyzed monthly profit growth trends
- Evaluated regional business performance
- Identified high-value customers
- Detected low-profit and loss-making product segments
- Compared profitability across customer segments

#Key Insights
- Technology category generated the highest overall sales.
- Certain sub-categories showed high sales but low profitability.
- Profitability trends increased significantly during later business periods.
- Regional performance varied considerably across markets.
- Customer purchasing behavior contributed heavily to overall revenue concentration.
